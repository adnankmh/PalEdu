# Lesson reader UX milestone

The reader now uses approved emerald/gold visual language and keeps all interactions linked to their existing real lessons and quizzes. Users can select explanation, test, and revision games, bookmark lessons, adjust font size, and edit **device-local** lesson notes.

Official PDFs, video/audio assets and annotations are not shown as playable unless real licensed links or uploads exist. Notes have a 2,000-character maximum, do not sync to cloud, and can be permanently cleared using the profile's local-data wipe.
