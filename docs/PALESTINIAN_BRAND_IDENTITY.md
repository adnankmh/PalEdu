# Palestinian brand integration

Approved visual: **book and flame without lettering** in Palestinian colors.
The source-aligned vector file `assets/brand/paledu_symbol.svg` is a
simplified silhouette traced from the approved PNG, optimized for scaling.
The exact high-definition image remains in the downloadable approved brand pack.

The Flutter entry and onboarding use PalEduBrandLogo instead of the generic crest.
Platform icons and splash graphics are generated by
`scripts/generate_brand_icons.py` from the versioned SVG. This provides
Android density icons, an Android native launch screen, Web/PWA icons, and
optional iOS icons when an iOS scaffold exists. Brand generation makes no
requests to external image hosts.

Build steps:
1. `flutter create --org io.github.adnankmh --project-name paledu --platforms android,web .`
2. `python3 -m pip install pillow cairosvg`
3. `python3 scripts/generate_brand_icons.py`
4. `flutter pub get && flutter analyze && flutter test`
5. `flutter build apk --debug && flutter build web --release`

GitHub Actions runs these automatically. Replacing the trace with the original
high-resolution PNG is possible later for pixel-exact store icon fidelity.
Do not store credentials or signed URLs in brand assets.
