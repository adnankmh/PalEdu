# PalEdu — Personal Reading Shelf

New screen controls **جميع الكتب / مفضلتي / متابعة القراءة** are attached to the in-app ministry library. Selecting a public ministry PDF records its title, approved ministry URL, last-read page, bookmark status and recent-read timestamp locally.

Users can resume where they stopped using the existing PDF viewer. No authentication material, private signed teacher file URLs or contents of the book are persisted by this feature. All reading history and legacy per-document metadata are deleted through the existing delete-my-data control. This is **not an offline book downloader**: remote PDFs still require a network connection when not cached by the PDF engine.

The scope of the shelf is device-local rather than cloud synced; account segregation and cross-device history are future features requiring secure back-end authentication.
